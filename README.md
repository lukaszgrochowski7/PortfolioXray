# Portfolio Xray

Portfolio analytics for beginners. Add the stocks you own and see how your portfolio is really doing: profit/loss, sector concentration, risk and momentum, explained in plain language.

> Status: work in progress (stage 1: basic portfolio).

## Planned features
- Add holdings and track profit/loss in %
- Sector and position concentration
- Risk metrics: volatility, drawdown, correlation
- Momentum indicators
- REST API, Docker, live deployment

## Disclaimer
This project is for education and analysis only. It does not give investment advice or recommend buying or selling any security.
